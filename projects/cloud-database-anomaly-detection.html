Project

Cloud Databases Anomaly Detection.

Project Overview

I developed a cloud database monitoring and anomaly detection solution during my work with Consumers Energy. Using Kusto Query Language (KQL), I analyzed enterprise-wide telemetry from Azure Log Analytics to extract resource-consumption insights across cloud databases. I then designed an Azure Workbook that consolidated database health and utilization metrics into a centralized monitoring interface.

The workbook continuously evaluated resources against defined thresholds and highlighted potential anomalies in metrics such as CPU utilization, storage consumption, and request units (RU). The resulting tool provided a more efficient way to identify abnormal resource behavior and helped transform large volumes of enterprise telemetry into actionable information for cloud infrastructure teams.

Key Technical Aspects

  • Kusto Query Language (KQL): Queried and filtered enterprise-wide Log Analytics data to isolate cloud database telemetry and resource-consumption metrics.
  • Azure Log Analytics: Worked with large-scale infrastructure telemetry to identify usage patterns and abnormal resource behavior.
  • Azure Workbooks: Built an interactive monitoring dashboard to aggregate database health and utilization information into a centralized view.
  • Anomaly Detection: Implemented threshold-based monitoring to identify resources exceeding expected limits.
  • Cloud Resource Monitoring: Tracked metrics including CPU utilization, storage, and request units (RU) to evaluate database performance and consumption.
  • Data Transformation & Visualization: Converted raw log data into structured metrics and visualizations that could be used for operational monitoring.
  • Enterprise-Scale Data Analysis: Designed queries and monitoring logic to operate across a broad set of cloud database resources rather than analyzing individual databases manually.

Project Impact

  • Manual adminsitrative workload reduced by 10%.
  • Critical alert detection increased by 32%.
  • False alert detection reduced by 17%.
