Project

Weight Controlled Labyrinth.

Project Overview

My team developed a weight-controlled robotic labyrinth that uses four load cells integrated into a custom fitness board to track a user's center of mass in real time. As the user shifts their weight, the calculated center of mass is translated into motor commands that control the tilt of a custom-built maze, allowing the user to navigate the course through physical movement.

The system combines embedded sensing, wireless communication, real-time motion control, and a custom user interface into a single interactive platform. A beam-break sensor detects when the marble reaches the end of the maze, stopping the gameplay timer and displaying the user's final time. A custom taring sequence allows the system to recalibrate between users and provide a consistent starting point.

Key Technical Aspects

  • Load-cell signal processing: Integrated four 50 kg load cells and four HX711 ADCs into a modified Wii Fit chassis to measure user weight distribution and convert strain-gauge signals into digital data.
  • Center-of-mass calculation: Developed algorithms to calculate the user's center of mass from the four load-cell measurements and translate weight shifts into target maze tilt positions.
  • Wireless communication: Implemented communication between the fitness board and labyrinth using ESP32-C6 modules and a custom Wi-Fi protocol to transmit center-of-mass data and system-state information in real time.
  • Embedded state management: Developed a shared state machine to coordinate Tare, Ready, Active Play, and Game Over states between the fitness board and maze.
  • Stepper motor control: Controlled two independent stepper motors to translate center-of-mass measurements into physical maze movement while implementing acceleration and deceleration profiles for smoother motion.
  • Real-time user interface: Developed an SPI-based display to provide live gameplay status, elapsed time, center-of-mass telemetry, and final performance metrics.
  • DMA audio processing: Leveraged Direct Memory Access (DMA) to stream a custom WAV victory theme to a speaker without blocking the microcontroller's primary execution loop.
  • Hardware interrupts:Hardware interrupts: Integrated an optical beam-break sensor as an external interrupt to detect when the marble completed the maze and immediately stop the gameplay timer.
  • Mechanical integration: Modified the fitness-board chassis and designed 3D-printed motor mounts, structural supports, and enclosures to integrate and protect the system's electronic and mechanical components.
